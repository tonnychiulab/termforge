## 🎯 一、 專案緣起與目標

針對社群對於終端機應用開發難度與 AI 結對編程工程能力的討論，本次工作旨在建立一個具備高度技術挑戰性的**系統級專案**作為驗證：
1. **堅持規格驅動 (SDD)**：依據 [OpenSpec](https://github.com/Fission-AI/openspec) 規範，在動手寫程式碼前完整產出提案 (Proposal)、行為場景 (Specs)、技術決策 (Design) 與任務清單 (Tasks)。
2. **純 Rust 硬核架構**：從零自製雙緩衝無閃爍渲染層、Generational Arena ECS、Quadtree 空間索引、固定時間步階物理模擬，零外部 C 語言依賴。
3. **極速跨平臺交付**：將終端應用無縫移植為 WebAssembly + xterm.js，搭載復古 CRT 掃描線光暈，自動化部署至 GitHub Pages 供大眾隨開隨玩。

## 🛠️ 二、 今日工作里程碑與進程

### 階段 1：需求互動探索與 OpenSpec SDD 基礎架構
- **多輪互動選型**：透過選項挑選確立「Terminal 遊戲引擎」、「純 Rust + termion」、「全功能模組一次到位」、「經典 Asteroids 示範遊戲」等關鍵方向。
- **子代理研究 (Research Subagent)**：指派背景子代理精準探勘 OpenSpec 官方倉庫，解析 RFC 2119 關鍵字、Gherkin 語法場景與工作流。
- **產出變更 1 規範 (`termforge-engine`)**：
  - `proposal.md`：痛點分析、8 大子系統能力清單與影響評估。
  - `specs/`：核心迴圈、雙緩衝 Diff、ECS、四元樹碰撞與 Asteroids 行為場景。
  - `design.md`：模組依賴圖、記憶體資料佈局與替代方案論證。
  - `tasks.md`：11 個分階段可測試實作檢核表。

### 階段 2：純 Rust 核心引擎與 Asteroids 原生開發
- **雙緩衝差分渲染器 (`render.rs`)**：
  - 維持前後兩塊 2D 字元緩衝區，計算每幀 Dirty-rect。
  - ANSI 游標跳轉最小化，徹底消滅 60 FPS 下全螢幕重刷的閃爍問題。
- **世代競技場 ECS (`ecs.rs`)**：
  - 自製 `GenerationalArena`，達成 $O(1)$ 的實體配置與回收。
  - 世代計數器 (Generation counter) 徹底杜絕 ABA 懸垂指標。
- **固定時間步階遊戲迴圈 (`engine.rs`)**：
  - 實作經典 Glenn Fiedler 60Hz 累加器模型，物理邏輯與渲染解耦。
  - 附帶 250ms 螺旋死亡 (spiral of death) 保護機制。
- **四元樹空間分割 (`collision.rs`)**：
  - 實作 2D Quadtree 空間索引，將密集實體碰撞複雜度由 $O(N^2)$ 降低至 $O(N \log N)$。
- **補間與粒子動畫 (`animation.rs`)**：
  - 30+ 種 Easing 緩動函數、物件池記憶體預配置粒子發射器。
- **終端機 RAII 保護鎖 (`terminal.rs`)**：
  - 進入 Raw 模式與 Alternate 螢幕，掛載 Panic Hook，確保崩潰時游標與終端狀態安全還原。
- **Asteroids 示範遊戲 (`games/asteroids`)**：
  - 向量慣性、小行星大中小三段分裂、爆炸粒子、HUD 生命與分數。
- **品質驗證**：單元測試 100% 通過，Release 二進制僅 **439 KB**。

### 階段 3：WebAssembly 移植與復古 CRT 網頁虛擬終端
- **產出變更 2 規範 (`add-web-wasm-support`)**：定義 Wasm 記憶體字串輸出與雙平臺靜態發布規範。
- **Wasm 橋接層 (`termforge_web`)**：
  - 針對 `wasm32-unknown-unknown` 編譯，藉由 `wasm-bindgen` 將每幀 ANSI Diff 送入瀏覽器。
  - WASM 體積精簡至 **76 KB**，毫秒級秒開。
- **復古 CRT 前端 (`dist/`)**：
  - 整合 `xterm.js` 與 `xterm-addon-fit`。
  - CSS3 硬體加速掃描線 (Scanlines)、螢幕暗角 (Vignette) 與螢光綠微光暈。
  - Web Audio API 純代碼 8-bit 合成音效（激光、打擊、爆炸音效）。
  - 手機觸控虛擬按鍵支援。

### 階段 4：九宮格戰術機動與操作指南小卡
- **產出變更 3 規範 (`enhanced-controls-and-abilities`)**：
  - 實作現代太空戰鬥機九宮格佈局：<kbd>W</kbd> 推進、<kbd>S</kbd> 主動煞車、<kbd>A</kbd>/<kbd>D</kbd> 轉向、<kbd>Q</kbd>/<kbd>E</kbd> 左右側平移、<kbd>X</kbd> 180° 瞬間掉頭、<kbd>Z</kbd>/<kbd>H</kbd> 超空間瞬移、<kbd>B</kbd>/<kbd>F</kbd> 全屏 EMP 炸彈、<kbd>P</kbd> 暫停、<kbd>M</kbd> 靜音。
- **產出變更 4 規範 (`add-in-page-controls-cheat-sheet`)**：
  - 在 CRT 螢幕正下方嵌入繁體中文優先的三欄式【🕹️ 戰術操作指南】霓虹對照小卡，讓初次體驗的朋友第一秒就能掌握所有操作。

### 階段 5：Git Flow、自動化部署與社群風格調整
- 初始化 Git 倉庫，建立遠端公開倉庫 `tonnychiulab/termforge`。
- 開啟 Pull Request #1 並自動完成合併。
- 利用 `git subtree` 自動將編譯產物發布至 `gh-pages` 分支，通過 HTTP/2 200 線上驗證。
- 更新全站文風，去除誇大行銷詞彙，轉為謙遜、客觀、低調的開源風格。
